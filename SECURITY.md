# Security Policy

## Supported Versions

Only the `main` branch is supported. Security fixes are not back-ported to
older revisions of this fork.

## Reporting a Vulnerability

If you discover a security vulnerability in this fork, **do not** open a
public issue. Instead:

1. Open a private security advisory through GitHub's
   ["Report a vulnerability"](https://github.com/Cyra-Systems/Paymenter/security/advisories/new)
   workflow on this repository, **or**
2. Email the maintainers (see the repository owner's profile for an
   address).

Please include a clear reproduction, the commit hash, and an indication of
impact. We aim to acknowledge within 72 hours.

## Upstream Vulnerabilities

Vulnerabilities in the upstream
[Paymenter](https://github.com/Paymenter/paymenter) project should be
reported through the upstream project's own security policy.
